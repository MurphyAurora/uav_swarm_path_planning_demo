# UAV Swarm Classic Path Planning Demo

这是一个适合 Windows Python 直接运行的“无人机集群经典路径规划算法复现”小项目。

不需要 Gazebo、不需要 ROS、不需要复杂仿真环境，只用 Python + Matplotlib 做二维可视化。

## 功能

本项目实现：

1. 多无人机集群路径规划
2. A* 经典栅格路径规划
3. RRT 经典随机采样路径规划
4. RRT* 优化随机采样路径规划
5. 多无人机轨迹同步采样
6. 无人机之间的安全距离检测
7. 集群路径可视化
8. 算法结果对比表和对比图

## 安装依赖

```bash
pip install numpy matplotlib pandas
```

## 运行

```bash
python main.py
```

运行后会在 `results/` 文件夹下生成：

```text
swarm_astar.png
swarm_rrt.png
swarm_rrt_star.png
comparison.png
metrics.csv
```

## 实验场景

默认设置 4 架无人机：

```text
UAV1: (5, 5)   -> (55, 55)
UAV2: (55, 5)  -> (5, 55)
UAV3: (5, 55)  -> (55, 5)
UAV4: (55, 55) -> (5, 5)
```

二维地图中设置多个圆形障碍物。每架无人机分别使用相同算法规划路径，然后对所有路径进行同步采样，检查任意两架无人机之间是否小于安全距离。

## 可用于报告的小结

本项目构建了二维无人机集群路径规划仿真环境，设置多架无人机在含圆形障碍物的空间中分别从起点飞向目标点。实验复现了 A*、RRT 和 RRT* 三类经典路径规划算法，并进一步加入多无人机同步轨迹采样与安全距离检测，用于判断集群飞行过程中是否存在潜在碰撞风险。实验结果包括集群轨迹图、总路径长度、规划时间、最小无人机间距、冲突次数和任务成功率等指标。该项目可作为无人机集群路径规划算法复现与可视化分析的基础版本.
